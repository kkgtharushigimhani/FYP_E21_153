Week 3

Sensor Selection, Hardware Operation & Budget Planning

Week 3 focused on choosing suitable sensors, comparing alternatives and building the practical operation plan for a smart wound monitoring patch.

Open Week 3 Drive Folder

Sensor operation

TMP117-based wound temperature sensing

The TMP117 was selected as the main temperature-sensing option because it provides high accuracy, digital I²C communication and a small package that can be integrated into a flexible sensor patch. The sensor must be placed near the wound interface while avoiding direct wet exposure.

  • Reviewed TMP119 and TMP117 datasheets.
  • Compared SHT45 and other alternatives for wound-patch suitability.
  • Prepared sensor operation and wound application notes.
  • Developed an initial manufacturing and budget plan.
