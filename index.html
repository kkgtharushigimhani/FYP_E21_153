Project Description

Ultra-low-cost flexible monitoring patch for diabetic wound care

The project focuses on a medical-grade flexible smart patch for diabetic foot ulcer monitoring. The disposable sensing patch is planned around an FPCB-based multilayer structure with temperature sensing, pH sensing, biocompatible wound-contact materials and a reusable ESP32-based data-acquisition module.

The monitoring concept is based on the fact that wound temperature, local perfusion, inflammation and pH changes can provide clinically useful information about healing progression. The final goal is to provide a low-cost prototype that can observe simulated wound conditions and support future therapy decision-making.

Core System Blocks

  • Flexible disposable FPCB sensing patch
  • TMP117 medical-grade digital temperature sensing
  • Screen-printed Carbon-PANI pH sensing concept
  • Hydrogel/passivation and ambient-shielded layers
  • Reusable ESP32 electronics, logging and alert logic

Main Engineering Direction

From biological wound evidence to sensor architecture

1

Clinical Need

Diabetic wounds require earlier detection of delayed healing, infection risk and microcirculation changes than visual inspection alone can provide.

2

Sensing Principle

Temperature gradients and pH-related changes are used as measurable wound microenvironment indicators.

3

Patch Design

FPCB layers place the TMP117 close to the wound interface while shielding the sensor from ambient temperature and wound exudate.

4

Data Module

ESP32 reads sensor arrays, converts digital readings, logs data and compares readings with clinical alert thresholds.
