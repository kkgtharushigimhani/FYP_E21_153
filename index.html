Project Description

Ultra-low-cost smart plaster for diabetic wound monitoring

IWMTAS is a biomedical instrumentation project focused on a disposable flexible sensing patch and a reusable electronic data-acquisition module. The selected wound parameters are temperature, pH and moisture/exudate, because these parameters can indicate inflammation, perfusion, infection risk and abnormal wound-bed conditions.

The design direction is practical for a student prototype: sterile sensing areas are kept disposable, while higher-cost electronics such as ESP32, ADC, op-amp conditioning and wireless/logging functions remain reusable.

Current System Concept

  • Flexible strip-like disposable patch
  • TMP117 multi-point temperature sensing
  • Carbon-PANI pH sensing concept
  • IDE moisture/exudate sensing
  • Reusable ESP32 + ADS1115 DAQ module
  • Supervisor-ready weekly portfolio and Drive evidence links
